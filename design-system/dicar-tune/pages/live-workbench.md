# Live Workbench Page Override

- A-style fixed engineering workspace with parameter navigation, typed editor, and waveform.
- Keep the status bar and bottom dirty-change bar visible without covering pane content.
- Dense values use tabular figures; units align in a stable column.
- Parameter errors stay beside the affected control.
- Waveform legend remains adjacent to Canvas and is keyboard operable.
- Encoder PPR, multiplier, and CPR appear as separate labeled fields in the same calibration section.
- Commit review is a focus-trapped dialog with a full before/after table and explicit permission state.
