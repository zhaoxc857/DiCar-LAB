# STM32F103 巡线车与 HC-05 接入说明

## 接线

适用于带稳压底板、标注工作电压 3.6–6 V 的 HC-05 模块：

| HC-05 | STM32F103C8T6 |
| --- | --- |
| VCC | 5V |
| GND | GND |
| TXD | PA10 / USART1_RX |
| RXD | PA9 / USART1_TX |
| STATE | 不接 |
| EN | 不接 |

HC-05 的串口逻辑电平为 3.3 V，STM32F103 可直接连接。不要同时用 ST-Link 的 3.3 V 和车辆电源给主板供电；调试时保留 SWDIO、SWCLK、GND 即可。

## 上位机

1. Windows 蓝牙设置中配对 HC-05，常见 PIN 为 `1234` 或 `0000`。
2. 双击根目录 `DiCAR_Launcher.bat`。
3. 车型选择“STM32F103 · 8路巡线车”。
4. 连接方式选择串口，选择 HC-05 的输出 COM 口，波特率保持 `9600`。
5. 连接后进入示波器，选择“巡线核心”工作组。

若系统为 HC-05 建立了两个 COM 口，优先选择属性中标为“传出/Outgoing”的端口。端口被其他串口软件占用时，先关闭该软件。

## 可调参数

| key | 含义 | 固件范围 |
| --- | --- | --- |
| `control_enabled` | 巡线电机使能，0 停止、1 启动 | 0 或 1 |
| `base_pwm` | 基础 PWM | 0–60 |
| `line_kp` | 巡线比例参数 | 0–20 |
| `line_kd` | 巡线微分参数 | 0–20 |

第一次启动时先架空车轮，确认波形和左右轮方向后再把 `control_enabled` 改为 1。

## 波形与协议

核心波形约 4 Hz：`line_error`、`line_bits`、`left_cps`、`right_cps`、`left_pwm`、`right_pwm`。8 路灰度和左右累计编码器约 1 Hz。当前没有电池 ADC。

协议是一行一个 JSON，以换行结束：

```text
{"type":"GET","key":"line_kp","seq":1}
{"type":"SET","key":"base_pwm","value":20,"seq":2}
{"type":"ACK","key":"base_pwm","value":20.000,"seq":2,"ok":true}
{"type":"TEL","data":{"line_error":0.125,"left_cps":1200,"right_cps":1180}}
```

该协议没有旧 DiCAR Tune 的 Hello/ParamRead 握手；连接成功后由参数 GET/ACK 和主动 TEL 帧确认链路。
